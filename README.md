# render-estimator-site

The public-facing page for the Render Estimator — what the tool is and the
principles it holds to.

**This repository exists so that nothing else has to be public.** The tool's own
repository is private and holds a real drawing's extracted text, client names,
trade sequences copied from a client's budget, and database backups. Serving a
page from there would have meant serving all of it.

Nothing in here may carry a project name, a client name, a rate or a price.

Published with GitHub Pages from the default branch, root directory.
